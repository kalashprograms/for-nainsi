# For Nainsi

Open `index.html` in a modern browser to view the website. The song uses the supplied audio file in `assets/` and attempts to begin automatically on page load. Some browsers block audible autoplay until the first tap; in that case, a romantic **One small tap** overlay appears and starts the song reliably when she taps it.

The site works as a self-contained static page. The Google Fonts load when an internet connection is available; graceful font fallbacks are included for offline viewing.
